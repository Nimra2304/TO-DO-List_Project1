# 📝 Python To-Do List Project

A simple and interactive command-line To-Do List application built in Python as part of Project 1. This program demonstrates core programming concepts including lists, loops, and user input handling.

## 🚀 Features
* **Default Tasks:** Pre-loaded with a starting set of tasks to get you going.
* **Interactive Addition:** Dynamically add your own custom tasks to the list using input prompts.
* **Continuous Loop:** Uses a `while` loop to let you add multiple tasks seamlessly until you decide to exit.
* **List Display:** Automatically loops through and prints out the updated to-do list.

## 💻 Technologies Used
* **Language:** Python
* **Key Concepts:** Lists, `.append()` method, `while` loops, `for` loops, and conditional statements (`if-elif-else`).
